SAFI NOURISH — GOOGLE SEARCH SETUP

This package contains only robots.txt and sitemap.xml. It does NOT overwrite your shopping cart, Paystack code or website pages.

1. Extract the ZIP.
2. In GitHub repository barakareshmy-cloud/safi-nourish-co, choose Add file > Upload files.
3. Upload robots.txt and sitemap.xml at the repository root, beside index.html.
4. Commit changes, and wait for Cloudflare deployment.
5. Confirm https://safi-nourish-co.pages.dev/sitemap.xml opens.
6. Open https://search.google.com/search-console and add a URL-prefix property: https://safi-nourish-co.pages.dev/
7. Verify ownership with the HTML file method; if Google provides a new HTML file, upload that file at the GitHub repository root and click Verify.
8. After verification, go to Sitemaps and submit sitemap.xml. Use URL Inspection to request indexing for the home page.

NEXT: The OLD copy of the website used a page title and meta description referring to WhatsApp. Ask ChatGPT to update SEO titles/descriptions and canonical tags using your newest GitHub ZIP, not your old site copy. Do not upload old HTML over the current checkout!

There is no guaranteed ranking or immediate change. Google controls its search results.
